# Parchment theme: assets

The neutral theme the web app ships with. Everything here is a placeholder
drawn in code; real art replaces it file by file without touching the
screens. A faction theme (ruled 2026-10-29: later, in the manner of Age of
Empires II) is a folder like this one: its own `theme.css` with the same
variables, and its own art.

| Asset | Today | Where it is used |
|---|---|---|
| `theme.css` | colours, typefaces, map inks | everywhere: the screens use only its variables |
| Paper texture | an SVG noise filter over the map | the map's ground |
| Terrain marks | SVG patterns: tree clusters, hill hatching, reed strokes | the map, per tile |
| Unit counters | squares in the side's colour with a role symbol (cross for foot, a diagonal for horse, an arc for bows, a point for scouts) | the map |
| Typeface | system serif (Iowan Old Style, Palatino, Georgia) | headings, dispatches |
| Icons | none; words on buttons | |

Wanted when there are assets: a scanned paper texture, hand-drawn terrain
marks, unit counter art per culture, a display typeface, a frame or border
per faction for the panels.
